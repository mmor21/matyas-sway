# Credits

## Origin

This configuration is based on the architecture and initial design of
**Archcraft's Sway edition** by Aditya Shakya <adi1090x@gmail.com>,
licensed under the MIT License.

Retained from Archcraft:

- The file structure — master config plus include fragments, and the
  scripts-per-action pattern
- The `theme.sh` self-modifying theming engine concept
- The rofi `.rasi` theme structure
- Several script structures (screenshot, lockscreen, rofi menu scripts)

Everything else — bar layout and modules, themes and palettes, fonts
and icons, keybindings, the network menu, and the installer — is this
project's own work.
